# 🚂 Деплой на Railway.app (самый простой способ)

## ✅ Преимущества Railway:
- Регистрация через GitHub за 10 секунд
- Деплой в **1 клик** из репозитория
- $5 бесплатных кредитов/месяц (~500 часов работы)
- Простой интерфейс, всё понятно

## 🚀 Пошаговая инструкция:

### Шаг 1: Открой Railway
**Ссылка:** https://railway.app/new

### Шаг 2: Deploy from GitHub repo
1. Нажми **"Deploy from GitHub repo"**
2. Авторизуй Railway через GitHub (аккаунт frizixx)
3. Выбери репозиторий: **frizixx/telegram-contact-bot**
4. Нажми **"Deploy Now"**

### Шаг 3: Добавь переменные окружения
После деплоя:
1. Открой своё приложение в Railway
2. Перейди в **"Variables"**
3. Добавь:
```
BOT_TOKEN=9199849245:AAGiYV8eYvgquBgmdBeoTpXKwnw5YoIaR6o
OWNER_ID=5226782090
```
4. Нажми **"Save"** — приложение автоматически перезапустится

## ⏱️ Время деплоя: 1-2 минуты

## 💰 Free tier:
- $5 кредитов/месяц
- Для легкого бота хватит на весь месяц
- После окончания кредитов — бот останавливается до следующего месяца

## 📊 Мониторинг:
- Логи в реальном времени прямо в Railway dashboard
- Видно статус: Running / Stopped
- Можно перезапустить одной кнопкой
