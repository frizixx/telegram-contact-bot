# 🤖 Telegram Contact Bot (Без рекламы!)

Твой личный контактный бот для Telegram. Пользователи пишут боту → ты получаешь сообщения с полной информацией об отправителе.

## ✨ Возможности

- ✅ **Без рекламы** — полностью твой бот
- 📨 Пересылка сообщений владельцу
- 👤 Информация о пользователе: ID, username, дата создания аккаунта, язык
- 💬 Возможность ответить пользователю через Reply
- 🚫 Антиспам (можно добавить rate limiting)
- 🆓 Бесплатный хостинг

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
npm install
```

### 2. Запуск бота

```bash
npm start
```

## 📋 Как использовать

### Для пользователей:
1. Находят твоего бота в Telegram
2. Пишут `/start`
3. Отправляют своё сообщение
4. Получают подтверждение

### Для тебя (владельца):
1. Получаешь сообщение с информацией:
   - User ID
   - Username
   - Имя и фамилия
   - Дата создания аккаунта
   - Язык интерфейса
   - Текст сообщения
2. Чтобы ответить — используй **Reply** на сообщение
3. Твой ответ автоматически отправится пользователю

## 🌐 Бесплатный хостинг

### Вариант 1: Render.com (рекомендуется)

```bash
# 1. Создай аккаунт на render.com
# 2. New > Web Service
# 3. Connect GitHub repo
# 4. Build Command: npm install
# 5. Start Command: npm start
# 6. Environment Variables:
#    BOT_TOKEN=твой_токен
#    OWNER_ID=твой_id
```

### Вариант 2: Railway.app

```bash
# 1. railway.app > New Project > Deploy from GitHub
# 2. Добавь переменные окружения
# 3. Deploy
```

### Вариант 3: Fly.io

```bash
fly launch
fly secrets set BOT_TOKEN=твой_токен OWNER_ID=твой_id
fly deploy
```

## 🛠️ Настройка

Отредактируй `.env`:

```env
BOT_TOKEN=твой_токен_от_BotFather
OWNER_ID=твой_telegram_id
```
