# 🤖 Telegram Contact Bot

Бот для связи с владельцем через Telegram.

## 🚀 Быстрый деплой (1 клик, БЕЗ карты)

### Railway (Рекомендуется)
[![Deploy on Railway](https://railway.app/button.svg)](https://railway.app/template/telegram-bot)

**После деплоя добавь переменные:**
- `BOT_TOKEN` - токен бота от @BotFather
- `OWNER_ID` - твой Telegram ID

---

## Или используй другие платформы:

### Replit (Always-on бесплатно)
1. Форкни на https://replit.com
2. Добавь Secrets (BOT_TOKEN, OWNER_ID)
3. Включи Always On

### Glitch
1. Импортируй на https://glitch.com
2. Создай .env с токенами
3. Добавь пингер для keep-alive

---

## 📦 Локальный запуск

```bash
npm install
node bot.js
```

## 🔧 Переменные окружения

- `BOT_TOKEN` - токен Telegram бота
- `OWNER_ID` - Telegram ID владельца

## ✨ Возможности

- ✅ Пересылка сообщений владельцу

- ✅ Сохранение истории сообщений
